<objective>
Set up the tsup build pipeline so that `npm run build` compiles `bin/cht.ts` + all `src/` into a single `dist/cht.js` with a `#!/usr/bin/env node` shebang. Update package.json to point `bin` to `dist/cht.js`, ship only `dist/` and `.claude/skills/`, and add `prepublishOnly` script. This fixes the broken npm global install (v2.0.0) where `--experimental-strip-types` shebang fails on many systems.

Purpose: Without a proper build step, `npm install -g @kosoukhov/cht-cli` produces a non-functional binary. This plan creates the foundation that all subsequent plans depend on.
Output: Working `dist/cht.js` produced by `npm run build`, validated by execution.
</objective>

  <action>
1. Install tsup as a devDependency:
   ```bash
   npm install -D tsup
   ```

2. Create `tsup.config.ts` at project root with this exact content:
   ```typescript
   import { defineConfig } from "tsup";

   export default defineConfig({
     entry: ["bin/cht.ts"],
     format: ["esm"],
     target: "node22",
     platform: "node",
     outDir: "dist",
     clean: true,
     splitting: false,
     banner: {
       js: "#!/usr/bin/env node",
     },
   });
   ```
   Per D-01: tsup/esbuild bundles bin/cht.ts + all src/ into single dist/cht.js.
   Per D-02: tsup adds shebang automatically via banner config.
   `splitting: false` ensures a single output file (import.meta.dirname will resolve correctly).
   All npm `dependencies` are auto-externalized by tsup (fuse.js, gray-matter, atomically, proper-lockfile, slug, zod).

3. Update `package.json` with these specific changes (per D-02, D-03, D-04, D-05):
   - Change `"bin"` from `{"cht": "bin/cht.ts"}` to `{"cht": "dist/cht.js"}`
   - Change `"files"` from `["bin/cht.ts", "src/", ".claude/skills/"]` to `["dist/", ".claude/skills/"]`
   - Add to `"scripts"`:
     - `"build": "tsup"`
     - `"prepublishOnly": "npm run build"`
   - Add `"tsup"` to `"devDependencies"` (done by npm install)

4. Add `dist/` to `.gitignore` (build output should not be committed):
   - Append line `dist/` if not already present

5. Run `npm run build` to verify the pipeline works and produces `dist/cht.js`.
